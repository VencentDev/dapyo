# Competitive Advantage

## 1. The Hiker Graph

The strongest long-term moat should be the network of:

- Hikers
- Hiking companions
- Hiking groups
- Trails
- Events
- Activity history
- Reputation
- Preferences

Over time, the system can understand:

- Who hikes together.
- Which trails users prefer.
- Preferred difficulty.
- Preferred days.
- Preferred hiking times.
- Which organizers are reliable.

This enables increasingly useful recommendations.

### Example

> "5 hikers near you are planning to hike Mt. Ulap this Saturday."

This recommendation becomes stronger as the network grows.

---

## 2. Hiking Reputation

Trust is important when users meet people from the internet.

A hiker profile could contain:

```text
Juan Dela Cruz

⭐ 4.9 Organizer Rating

🥾 32 Completed Hikes
🏔️ 18 Mountains
👥 28 Group Hikes

96% Attendance
12 Hikes Organized

Reliable Hiker
```

Reputation can be based on:

- Completed hikes.
- Attendance.
- Organizer reviews.
- Community contributions.
- Successful events.
- Reports and moderation history.

---

## 3. Intent-Based Social Network

Most fitness networks revolve around completed activities.

This platform can revolve around **future intent**.

Example:

> "I'm hiking Mt. Daraitan on Saturday."

Other users can discover and join.

This creates a social network around future activities, not only historical activities.

---

## 4. Structured Hiking Events

Instead of:

> "LF joiners Mt. Pulag this weekend"

Users get:

```text
Mt. Pulag
September 20
Moderate / Hard
8 / 15 participants
Organizer: Juan
⭐ 4.9

[JOIN HIKE]
```

This makes hiking communities searchable and actionable.

---

## 5. Gamification + Real-World Participation

Gamification should reward actual hiking behavior.

Examples:

- Completed hikes.
- New mountains.
- New trails.
- Group participation.
- Organizing events.
- Community contributions.

The goal is to encourage:

**More hikes → more connections → more activity → stronger network**

---

# What Is NOT a Strong Moat?

These features can be copied easily:

- Badges.
- XP.
- Leaderboards.
- Dark mode.
- GPS tracking.
- Basic social feeds.

The moat should come from the **network and data generated by real hiking participation**.
