# Gamification System

## Goal

Gamification should increase:

- Participation.
- Retention.
- Exploration.
- Community contribution.
- Repeat hiking.

It should not exist only as decoration.

---

# XP

Users earn XP for meaningful actions.

Potential examples:

| Action | XP |
|---|---:|
| Complete hike | +100 |
| Discover new mountain | +150 |
| Join group hike | +50 |
| Organize hike | +100 |
| Help community | +25 |
| Complete challenge | +250 |

Values should be balanced after collecting real usage data.

# Mountain Collection

This could become one of the most engaging features.

Users collect mountains:

```text
Philippine Mountains

☑ Mt. Daraitan
☑ Mt. Ulap
☑ Mt. Batulao
☐ Mt. Pulag
☐ Mt. Apo
☐ Mt. Guiting-Guiting
```

This creates a natural long-term progression system.
