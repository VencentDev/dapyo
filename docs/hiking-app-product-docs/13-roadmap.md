# Product Roadmap

## Phase 0 — Validation

Before development:

- Interview hikers.
- Interview organizers.
- Validate the "find and join a hike" problem.
- Create clickable prototype.
- Test with real hikers.
- Identify initial geographic market.
- Identify initial hiking communities.

Success condition:

Users express strong interest in using a dedicated platform and preferably agree to join a pilot.

---

# Phase 1 — MVP

Build:

- Authentication.
- Profiles.
- Mountain database.
- Create hike.
- Discover hikes.
- Join / leave.
- Participant management.
- Basic event chat.
- Activity completion.
- XP.
- Badges.
- Social feed.
- Notifications.
- Reporting.
- Admin panel.

Primary goal:

**Get people to complete group hikes.**

---

# Phase 2 — Retention

Add:

- Better recommendations.
- GPS activity tracking.
- More achievements.
- Challenges.
- Leaderboards.
- Follow users.
- Hiking groups.
- Better organizer profiles.
- Attendance history.

Goal:

**Make users come back regularly.**

---

# Phase 3 — Safety

Add:

- Trip check-ins.
- Emergency contacts.
- Live location sharing.
- Expected return time.
- Safety alerts.
- Offline maps.

Goal:

**Make the platform useful before, during, and after the hike.**

---

# Phase 4 — Future Ecosystem Exploration

Only begin this phase after the app is successful and has a strong, active
community. The app remains totally free; this phase does not introduce
subscriptions, premium plans, paid events, payment processing, or transaction
fees.

Explore, without committing to implementation:

- Business profiles.
- Guide and tour-operator discovery.
- Transportation and camp information.
- Equipment and outdoor-business information.
- Whether a marketplace would genuinely help the hiking community.

Goal:

**Expand the ecosystem only when it strengthens the free core product.**

---

# Phase 5 — Deferred Hiking Marketplace

This is a future possibility only, and should be considered only after the
app is demonstrably successful. No marketplace pricing or payment model is
defined now.
