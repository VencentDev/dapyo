# Safety and Trust

## Why Safety Matters

The platform connects people who may not know each other.

This creates a trust and safety problem.

Users need confidence that:

- Organizers are legitimate.
- Participants are real people.
- Events contain accurate information.
- Bad actors can be reported.
- Important trip information is available.

---

# MVP Safety

Implement:

- User reporting.
- User blocking.
- Event reporting.
- Organizer profile.
- Attendance history.
- Basic organizer reputation.
- Admin moderation.
- Account verification where practical.

# Future Safety Features

After product validation:

- Trip check-in.
- Trip check-out.
- Emergency contact.
- Scheduled safety reminders.
- Live location sharing.
- SOS.
- Route sharing.
- Expected return time.
- Offline maps.

These should be designed carefully because safety features create high reliability expectations.

The application should never imply that an SOS or tracking feature guarantees emergency response unless an actual emergency-response system exists.
