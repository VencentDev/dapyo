# Core User Flows

## Flow 1 — New Hiker

```text
Install App
    ↓
Create Account
    ↓
Complete Profile
    ↓
Select Hiking Preferences
    ↓
Discover Upcoming Hikes
    ↓
Open Hike
    ↓
Review Organizer + Participants
    ↓
Join
    ↓
Receive Notifications
    ↓
Attend Hike
    ↓
Complete Activity
    ↓
Earn XP / Badge
    ↓
Share Activity
```

---

# Flow 2 — Organizer

```text
Create Account

Set Mountain

    ↓

    ↓

    ↓
Manage Participants
    ↓
Communicate
    ↓

    ↓

    ↓

```

# Critical Product Loop

```text
Discover Hike
      ↓
Join Hike
      ↓
Actually Attend
      ↓
Complete Hike
      ↓
Earn Reward
      ↓
Share Achievement
      ↓
Discover Another Hike
```

This loop should be optimized before adding secondary functionality.
